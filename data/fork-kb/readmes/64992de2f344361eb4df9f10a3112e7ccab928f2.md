## 一、 核心架构与技术改进

本项目在原生 Strata 引擎基础上完成了 6 大核心维度的重构与性能榨取：

### 1. 彻底的工程解耦与物理隔离 (v3 Monorepo Isolation)
- 剔除了上层工作流代码与实验性文件的干扰，在单体引擎闭包中固化全部运行环境与启动参数；
- 提供原生脚本与桌面快捷启动器，支持多环境无缝迁移。

### 2. 专为 Windows AMD 开发的原生硬件遥测 (`_WindowsAmd`)
- **破局根因**：解决原版 Strata 仅支持 Linux sysfs（`/sys/class/drm`）导致的 Windows AMD 显卡监控“全黑屏”问题（原版因 `gpu.ok() == False` 屏蔽全部 GPU 仪表盘）；
- **显存与设备识别**：通过 ROCm 原生 `amdhip64_7.dll`（`hipMemGetInfo` / `hipDeviceGetName`）实时捕获 **107.65 GB UMA 显存池**与当前显存占用；
- **核心利用率**：接入 Windows 原生性能数据计数器（PDH）聚合引擎 `\GPU Engine(*)\Utilization Percentage`，捕获 3D/Compute 核心负载；
- **整机功耗**：接入 Windows RAPL 计数器 `\Energy Meter(rapl_package0_pkg)\Power`，以毫瓦级高精度换算并实时渲染 APU Package 整机功耗曲线（20~35W）。

### 3. 全量 24,576 MoE 专家 100% 锁定显存
- 参数 `--expert-cache 20000 --no-prefill-borrow`：
- 全部 24,576 个 MoE 专家（46.84 GiB）一次性锁定在 UMA 显存中；
- 开启 `--no-prefill-borrow` 保护专家槽位不被借用，彻底消除了超长 Prompt 预填充借槽引发的 NVMe SSD Direct-I/O 寻道抖动，实现真正的 **0 磁盘读取开销**。

### 4. 256K 超长上下文 INT8 KV Cache 零压力常驻
- 参数 `--max-context 262144 --kv int8 --kv-resident 262144`：
- 利用 36 层 GDN 线性注意力 + 12 层 QSA 全量注意力的拓扑特性，将 256K 全窗口的 `3.09 GiB` INT8 KV 完全常驻在显存中；
- 全模型载入与全量 KV 初始化完成后，系统依然富余 **47.0 GiB** 空闲显存。

### 5. 精简 57K Draft 词表 + MTP 5-Draft 投机推测解码
- 参数 `--mtp-draft-vocab draft_vocab_zh57k.bin --spec 5 --spec-min-p 0.35 --lookup-chain 3`：
- 剔除生僻 CJK Ext 字符，将 Draft Head 词表由 10 万+ 精简至 56,919 个高频中英代码词，矩阵扫描显存带宽开销降低 46%；
- 投机推测接受率稳定在 **45% ~ 60%**，解码速率相较基线串行提升约 **1.6 倍**。

### 6. Strix Halo (gfx1151) 16 项硬件加速开关矩阵
- 全面激活针对 RDNA 3.5 矩阵核心的优化：
  `GDN_HEAD`, `GDN_PP`, `GDN_CONVL2`, `GDN_NOY`, `CVEC_FUSE`, `HCD_EXACT`, `PF_PAD`, `Q8_PACKED`, `Q6_PACKED`, `MMVF_ROWS`, `ATTN_LANECELL`, `EXPERT_V2`, `TSUM`, `LFUSE`, `GDN_SPLIT`, `QFUSE`；
- 配合定制的 Windows ROCm `hipBLASLt 100500` 调优表，实现 8-Token Zero-Doorbell 静态图捕获。

## 二、 实测 Token 吞吐性能区间

在 AMD Ryzen AI Max+ 395 硬件平台上的端到端实测表现如下：

### 1. Prefill（提示词预填充吞吐区间）
由于 30B MoE 大模型在 GPU 上建立计算图、算子唤醒与显存同步存在约 **0.5 ~ 0.6 秒的固定底噪延迟**，吞吐速率随 Prompt 长度平摊表现出清晰的区间特性：

| 提示词长度规模 | 耗时区间 | Prefill 吞吐速度 | 场景说明 |
| :--- | :--- | :--- | :--- |
| **超短交互 (< 100 tokens)** | ~0.5 - 0.7 秒 | **100 ~ 150 tok/s** | 单句日常打招呼、极短命令（如 61 tokens 耗时 0.6s，计算值为 101 tok/s） |
| **典型对话 (500 ~ 2,000 tokens)** | ~1.5 - 2.5 秒 | **500 ~ 900 tok/s** | 常见多轮对话、单段代码修改要求 |
| **中长文本 (4,000 ~ 10,000 tokens)** | ~3.5 - 8.0 秒 | **1,000 ~ 1,200 tok/s** | 单篇学术论文摘要、完整源文件分析 |
| **超长批处理 (20,000 ~ 40,000+ tokens)** | ~15 - 31 秒 | **1,200 ~ 1,350+ tok/s** | 全书/项目级上下文，实测 40,030 tokens 耗时 31.0s，达 **1,287.2 tok/s** |

> **提示**：当在 Web UI 中开启深度思考（`reasoning_effort: high`）时，若 Prompt 较短，前端卡片在后续长达数分钟的生成过程中会静态保留显示开头的 Prefill 成绩（如 `101 t/s`），此为前端字段停留机制，并非预填充性能卡死。

### 2. Decode（输出生成解码吞吐区间）

| 解码模式与场景 | 吞吐速率区间 | 提升幅度 |
| :--- | :--- | :--- |
| **纯 APU 串行无投机推测 (Baseline)** | **32 ~ 36 tok/s** | 1.0x (基线) |
| **MTP 投机推测：日常中文对话 / 长篇论述** | **45 ~ 54 tok/s** | 约 1.4x ~ 1.5x |
| **MTP 投机推测：高深度思考推理 (Thinking Phase)** | **48 ~ 58 tok/s** | 约 1.5x ~ 1.6x |
| **MTP 投机推测：代码编写 / 结构化 JSON 生成** | **58 ~ 65+ tok/s** | 约 1.7x ~ 1.8x (高接受率) |

## 三、 硬件与软件环境要求

- **处理器/显卡**：AMD Ryzen AI Max+ 395 (Strix Halo APU, Radeon 8060S, `gfx1151`)
  *(亦可在 64GB+ 内存的同构 RDNA3/3.5 APU 或 ROCm 支持显卡上按比例调减 expert-cache 运行)*
- **统一显存 (UMA)**：建议 64GB ~ 128GB LPDDR5X-8000
- **操作系统**：Windows 11 64-bit (22H2 或更高版本)
- **显卡驱动**：AMD Software: Adrenalin Edition 24.12+ (带完整 HIP 运行时)
- **Python 环境**：Python 3.10 ~ 3.13 64-bit

## 四、 快速部署与引导向导 (Onboarding & Setup)

为确保在不同机器、盘符或新环境下的零门槛部署，本项目提供了 **双模引导体系**（一键 Windows 向导 + AI Agent 引导部署 Skill）：

### 方式 A: 零门槛一键向导 (推荐新用户)
直接双击根目录下的 **`SETUP-WIZARD.bat`**：
1. **自动环境检测**：校验 Win11、AMD HIP 运行时、8060S APU 识别与 UMA 显存容量；
2. **智能定位模型**：全盘自动扫描本地 GGUF 模型文件并智能匹配，支持手动自定义路径；
3. **显存自适应调优**：依据 UMA 显存大小自动设定 `--expert-cache`（$\ge 64\text{GB}$ 设为 24576 全专家常驻）；
4. **生成桌面图标**：自动在桌面创建 `Strata Qwen IQ3_S v3.lnk` 快捷启动项；
5. **一键拉起服务**：配置完毕后支持直接启动。

### 方式 C: 手动命令行配置与启动

#### 1. 克隆代码仓库
```bash
git clone https://github.com/your-username/gfx1151engine-v3.git
cd gfx1151engine-v3
```

#### 2. 创建并激活 Python 虚拟环境
```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

#### 3. 配置模型路径
根据模板文件 [strata-qwen-iq3s-v3.example.json](file:///E:/gfx1151engine-v3/strata-qwen-iq3s-v3.example.json) 创建您的配置文件 `strata-qwen-iq3s-v3.json`：
```json
{
  "args": [
    "--pack", "Strata-data/packs/gsq-rco-iq3_s",
    "--native", "D:/Models/Qwen/Qwen3.8-Flash-Next-GSQ-RCO-IQ3_S-00001-of-00002.gguf",
    ...
  ]
}
```
> 将 `--native` 后的路径替换为您本地存放 `Qwen3.8-Flash-Next-GSQ-RCO-IQ3_S` 原生 GGUF 分片的实际路径。

#### 4. 一键启动
双击运行 `START-QWEN-IQ3S-V3.bat`，或在命令行中执行：
```powershell
.\START-QWEN-IQ3S-V3.bat
```
启动成功后，浏览器将自动打开 Web Monitor 监控看板：
`http://127.0.0.1:8080` (包含 Chat 对话、Monitor 硬件看板、API 诊断追踪)。
