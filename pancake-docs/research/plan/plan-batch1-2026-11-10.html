Overview: where the gain is

Decode is bound by reading expert bytes (CPU experts from DDR4, GPU experts from VRAM), and agent turns lose time to prompt re-reads. So the large gains are in: fewer expert bytes on the critical path (routing, placement, overlap), no repeated prompt reads between turns, and more accepted tokens per verify window. GPU kernel work is a smaller, mostly exact floor (+2-5%). The areas below are ordered by total expected gain.
