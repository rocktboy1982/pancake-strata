Overview: where the gain is

Decode is bound by reading expert bytes (CPU experts from DDR4, GPU experts from VRAM), and agent turns lose time to prompt re-reads. So the large gains are in: fewer expert bytes on the critical path (routing, placement, overlap), no repeated prompt reads between turns, and more accepted tokens per verify window. GPU kernel work is a smaller, mostly exact floor (+2-5%). The areas below are ordered by total expected gain.

Method-validity research and development order (2026-11-11, deep-research: 104 agents, 22 sources, 20 of 25 verified claims kept)

Every published gain below was measured on NVIDIA GPUs over PCIe 4.0 with fp16/bf16/Q4 experts on Mixtral-class or 16B-class MoEs. None used IQ2_XS/Q2_0 experts, gfx1100, PCIe 3.0 or DDR4, so no paper's speedup is assumed to transfer: each item is built as an offline/CPU-testable piece first and only gets an engine switch if the replay shows a gain. The research covered the cache/prefetch, mixed-precision, speculative-MoE and pruning papers; it did not cover 16.7, 16.10 or the Q2_0/IQ kernel items (those still need their own source checks, done by the kernel wave). Skip unless an offline replay shows value for single-user decode: OD-MoE shadow model (needs the whole model re-run ahead; recall measured on Mixtral only), MoE-Infinity EAM collection (needs 30-50 requests of warm-up; kept only as the FineMoE baseline). Do not build naive shared-expert + top-r self-drafting: in the DraftExpert paper it was slower than autoregressive once exact verification and repair were counted. HybriMoE is a design reference only (scheduler depends on measured CPU/GPU latencies; "exact and offline-simulable" was refuted 0-3). SP-MoE (draft-stage expert prediction) was measured at batch 1, greedy, sequential drafting, PCIe 4.0: reference for A22/A26, no gain assumed. Claims that must not be repeated as facts (refuted in the verification): MoE-Infinity's smallest gains on Mixtral with a 17% vs 21% buffer hit rate; OD-MoE being unusable on 20 GB because of a 45 GB shadow node; HybriMoE being exact; EcoSpec's "about 11% relative"; SP-MoE's speedup min/max summary. Open: whether the HOBBIT proxy and FineMoE matching hold on a many-expert Qwen-class MoE with IQ2_XS experts, and the d, thresholds and cache sizes that fit 20 GB VRAM on PCIe 3.0. Testing: why 45-minute windows, and what changes (measured 2026-11-11)

Target: a 45-minute spec in about 5-8 minutes.

  • One attempt = one engine start + one measurement. Median 118-126 s per attempt; the measurement itself is 13 s in the confirm specs (512 tokens at ~125-140 tok/s plus the prompt): about 90% of every attempt is engine start-up and warm-up.
